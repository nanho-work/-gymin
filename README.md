# 산하의 맹약 — 게임 기획 기록실

기존 GymIn 프로젝트를 한국풍 턴제 RPG의 시각적 기획 공간으로 전환하고 있습니다. **게임명과 세계관은 아직 제안 초안**이며 사용자가 확정한 설정이 아닙니다.

## 현재 화면

- `/`: 세계관 카드 4개, 클릭 가능한 지역·세력 개념 지도, 미정 항목
- 이야기 흐름: 서막부터 종막까지의 제안 구조
- 인물 도감: 준비 공간. 등록된 인물과 제작된 초상화는 아직 없습니다.
- 변경 기록: 수정 전/후, 수정 이유, 초안/확정 상태
- 세계관과 변경 이력 조회

## 기록 보관 방식

사이트는 읽기 전용입니다. 대화에서 논의한 내용을 로컬의 `web/src/features/game-world/data/world.json`에 반영하고 history에 날짜·변경 이유·이전/이후 내용을 기록합니다. 사용자가 커밋·푸시·배포하면 모든 기기에 같은 내용이 표시됩니다.

사이트 편집·내보내기·브라우저 저장·별도 DB는 사용하지 않습니다. 기존 브라우저 저장값은 읽거나 삭제하지 않습니다.

## 개발

```sh
npm install
npm run dev
npm run build
```

Next.js + React + TypeScript. 화면 구현은 `web/src/features/game-world/pages`, 데이터는 `data`, 홈 진입점은 `web/app/page.tsx`에 있습니다. 모바일에서도 열 수 있는 반응형 화면입니다.

## 기존 프로젝트와 배포

기존 구인 서비스의 서버·DB·인증·경로는 보존했습니다. 신규 홈에서는 기존 인증/API를 호출하지 않습니다. EC2는 사용을 종료했으며 자동 배포 워크플로와 Vercel 빌드 생략 설정을 제거했습니다. 현재 배포 대상은 Vercel의 `web` 프로젝트입니다. 커밋·푸시·실제 배포는 사용자가 직접 진행합니다. 검색 색인 제외 설정은 접근 제한이나 로그인 보안을 대신하지 않습니다.

이전 안내는 [기존 README](docs/game/legacy-project-readme.md), 이전 작업 규칙은 [기존 AGENTS](docs/game/legacy-agents.md)에 있습니다. 기존 인프라 문서는 참고용이며 게임 서버 연결 완료를 의미하지 않습니다.

## Vercel 배포 설정

- Root Directory: `web`
- Framework Preset: Next.js
- Build Command: `npm run build`
- Output Directory / Install Command: 기본값 (Override 끄기)
- Ignored Build Step: Automatic
- Node.js: 22.x (프로젝트의 `engines.node` 요구 범위 내)

현재 게임 기획 홈은 EC2 API 없이 동작합니다. 남겨 둔 기존 구인 서비스의 API 기능은 Vercel로 이식한 상태가 아닙니다. 설정 정리만으로 배포 완료를 의미하지 않으며, 푸시 이후 Vercel의 배포 결과를 확인해야 합니다. 자세한 경계는 [배포 안내](docs/deployment-boundaries.md)를 참고하세요.

## 전체 캠페인 설계 v0.1

이야기 메뉴에 6막·44개 전투안과 분기 흐름도를 표시합니다. 공통20 + 선택 경로8 + 합류8 = 한 회차36전투입니다. 계획 데이터는 `web/src/features/game-world/data/campaign.json`입니다. 경로 필터와 전투별 목표·패배조건·결과 열람을 지원합니다. 역사적 사실과 창작을 구분한 설계 초안이며 게임 구현 완료를 의미하지 않습니다.

### 인물 비교 도감
홈의 인물 메뉴에서 원본 512개 슬롯을 이름·추천 이름·병과로 검색합니다. `web/src/features/game-world/data/characters.json`과 `public/images/jojo-reference`는 원본 비교 자료이며 새 게임 외형이 아닙니다. 재생성은 `python3 scripts/game/import-character-reference.py <기존 추출 assets 경로>`로 합니다. 기본 능력값은 전투 최종 수치가 아니며, 창작 이름은 가칭입니다. 교체안은 왕건 외 미확정입니다.

주요 아군 8인의 상세 추천은 `web/src/features/game-world/data/ally-proposals.json`에서 관리합니다. 원본 재추출 데이터와 분리하여 가져오기를 다시 실행해도 보존됩니다. 화면과 검색에는 상세 추천이 우선 적용됩니다. 역사 근거·창작 성격·제안 병과·합류 및 퇴장 제약을 구분하며 모든 후보는 미확정입니다.

메뉴별 주소: `/world` 세계관, `/story` 이야기, `/characters` 인물, `/history` 개발 기록. `/`는 기존 세계관 진입점입니다. 각 경로는 새로고침·직접 접속을 지원하며 기존 구인 서비스 레이아웃과 인증을 적용하지 않습니다.

인물 교체 유형은 1차 제안으로 실존·창작 인간·설화 존재·통합 검토·배역/소품을 구분합니다. 설화 동료와 개인 임무 초안은 `folklore-plan.json`에서 관리하며 전승과 각색, 직접 근거 미확인을 구별합니다. 원본 슬롯 삭제나 실제 게임 교체는 하지 않습니다.

설화 후보는 총 10명으로 확장했습니다. 기존 3명만 원본 슬롯에 연결되고 신규 7명은 독립 후보입니다. 인물 페이지 상단에서 전원 확인하며, 하단 원본 도감 필터의 수와 구별합니다. 모든 기원 각색·성격·병과·왕건 영입담은 제안입니다.

### 설화 캐릭터 콘셉트 v1

인물 페이지의 10명 전신 초안은 `web/public/images/folklore/`에 보관합니다. 내장 이미지 생성 도구로 제작한 창작 외형이며, 전승의 고증 복원도나 최종 게임 스프라이트가 아닙니다. 정확한 생성 프롬프트는 `scripts/game/folklore-image-prompts.json`에 기록했습니다. 프로젝트에는 512px WebP 전신과 128×160px WebP 썸네일만 저장합니다. 클릭하면 512px 전신을 엽니다. 기존 대형 PNG의 프로젝트 복사본은 경량본으로 대체했습니다.

생성 도구에 별도 저장된 설화 후보 원본 10장도 2026-10-25 정리했습니다. 현재 경량 이미지 20개 합계는 383,494바이트입니다. 이후 이미지 저장 및 카드 배치 기준은 `AGENTS.md`를 따릅니다.

몽당 모션 초안: `mongdang-motion-v1.webp`(4열×3행), 대기·걷기·공격 각 4프레임. 인물 카드에서 동작 선택과 재생·정지를 지원합니다. 한 방향 검토용이며 최종 게임 모션은 아닙니다. 생성 프롬프트는 `scripts/game/mongdang-motion-prompts.json`, 대형 생성 원본은 경량본 확인 후 정리했습니다.

몽당 모션 v2: `web/public/images/folklore/mongdang-motion-v2/`에 4방향×4동작×4프레임(160px WebP, 총 388,600바이트). 실루엣 단위 분리와 하단 기준선 정렬을 적용하며 페이지에서 방향·동작·프레임을 선택합니다. 프롬프트와 프레임 목록은 `scripts/game/mongdang-motion-v2-*.json`에 기록합니다. 큰 생성 원본은 정리했습니다.

설화 후보 10명 모두 얼굴 초상화 v2와 4방향 모션 선택기를 사용합니다. 초상화 10장 합계 60,916바이트, 모션 640장 합계 3,391,640바이트(몽당 기존 포함)입니다. 생성 프롬프트는 `scripts/game/*-v2-prompts.json`, 용량 목록은 `scripts/game/folklore-art-v2-manifest.json`, 공통 제작 절차는 `docs/game/character-art-workflow.md`에 기록했습니다. 이번 대형 생성 원본은 정리했습니다. 비교용 초안이며 프레임별 형태·시선 각도·동작 연결은 최종 게임 적용 전 보완 대상입니다.

몽당 모바일 가독성 시안 v3: 인물 페이지 상단에서 기존 모션과 신규 5시 방향 16프레임(약 90KB)을 크기·배경별로 비교합니다. 다른 인물과 나머지 방향에는 아직 적용하지 않았습니다.

아이템 도감 `/items`: 원본 104개(무기 38·방어구 15·보조구 34·소모품 17)를 이미지·설명·가격·병과 허용표·상점 진열 ID와 함께 표시합니다. 이름/설명 검색과 분류/병과 필터를 제공합니다. 32×32 PNG 104장 합계 47,362바이트. 재추출 스크립트는 `scripts/game/import-item-reference.py`, 데이터는 `web/src/features/game-world/data/items.json`입니다. 새 게임 교체안과 장착 외형, 이벤트별 입수 경로는 별도 후속 작업입니다.

아이템 교체 시안 v1: `/items` 상단에서 나무곤봉→나무몽둥이, 구리갑옷→쇠편 가죽갑옷 두 개만 우선 비교합니다. 원본 값은 유지하며 설화 10명 착용 제안은 미확정입니다. 256px WebP 2장 합계 22,338바이트. 나머지 102개는 사용자 디자인 검토 후 진행합니다.
