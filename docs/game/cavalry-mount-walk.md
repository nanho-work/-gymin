# 기병 공통 말 보행 · 2026-10-26

## 연결 범위
홍유의 탑승 이동에 적용. 기본 말(-1), 가죽말갑(57), 쇠편말갑(58), 새벽갈기(60), 그늘발(61), 불꽃굽(62), 물안개(63) 모두 4단계 보행. 앞 SE/뒤 NW 각4장, SW/NE는 좌우 반사하여 4방향 지원. 승급3단계 및 창6종과 함께 사용한다.

## 공통 코드
`web/src/features/game-world/model/cavalryMount.ts`의 `cavalryMountPose(accessory,direction,walking,frame)`가 이미지와 말의 위치, 기수의 수직 이동량을 반환한다. 보행은 190ms × 4단계. 말과 기수가 같은 단계와 수직 이동값을 사용한다. 장비 교체는 프레임 진행 상태를 리셋하지 않는다. 비기마 보조는 기본 말로 처리한다.
다른 기병은 이 함수를 재사용하고 자신의 몸체 중심/안장 오프셋을 설정한다. 말 프레임을 장수별로 복사하지 않는다. 현재 다른 장수 카드의 기존 일체형 이미지를 자동 교체한 것은 아니다.

## 자산
`web/public/images/mounts/walk-v1/{id}/{se,nw}-{0,1,2,3}.webp`.
56개, 각160×160, 합계574,978bytes(약562KiB), 평균약10KiB. 기존 정지 말은 대기/공격/스킬에서 유지한다. 이동은 새 보행 이미지로 전환한다. 기수 공격/스킬은 기존 관절 조합이며 이번 작업 범위는 말 보행이다.

## 제작 및 기준
built-in imagegen, 기존 말의 SE/NW 두 이미지를 각 말의 참조로 사용했다.
프롬프트: 같은 말의 색·안장·마갑·장식·실루엣 유지. 기수 없는 투명 배경 4열×2행 보행 스프라이트. 첫행SE앞, 둘째행NW뒤. 뛰기가 아닌 다리를 교대로 들어 딛는 네 단계. 안장 위치와 몸통 크기 일정, 발·꼬리·머리 잘림 금지, 글자/그리드/그림자 금지.
원본 시트에서 실제 연결된 알파 영역을 분리한다. 단순 균등 셀 크롭은 경계에 걸친 머리/꼬리를 자를 수 있으므로 사용하지 않는다. 한 방향 네 프레임에 같은 축척을 사용하고 상단을 정렬한다. 경량본 연결 후 이번 생성 원본7개는 삭제한다.
