# 장수 대표 복식 초상화 v3 · 2026-10-26

## 적용 기준

왕건부터 이름이 정해진 교체 인물과 장영실까지 17명 전체. 초상화는 대표 신분·성격·병과의 시각적 소개이며 최초 지급 장비를 표시하는 플레이 스프라이트와 별도다. 기존 병과·수치·이동거리·모션·이름 대응은 유지한다. 얼굴의 기본 정체성은 v2를 참조했다.

역사 복원화가 아니다. 실존 인물의 정확한 외모·연령·수염·흉터는 확인한 사실이 아니며 게임용 창작이다. 병과 역시 원본 게임의 역할이다. 궁병 이미지가 실제 인물의 전용 군사 직종을 입증하지 않는다.

## 자료와 적용 한계

- 태조 동상: 사후 조성된 상징물의 통천관 추정 형태·원형 장식을 왕건의 관에 차용. 918년 실제 착용 관이라고 설명하지 않는다. 예복 색과 무늬는 창작.
- 복두: 신라에서 고려로 이어진 관모 전통과 관복의 유형 참고. 초기와 후대 제도를 혼합해 정확한 품계라고 주장하지 않는다. 짧은 각과 접힌 관모 실루엣은 가독성을 위한 단순화다.
- 군장: 철제 투구·찰갑의 구조 참고. 자료가 다루는 삼국시대·후대 고려와 후삼국은 시기가 다르며 특정 장수의 소유품이나 10세기 군장 복원이 아니다.
- 경순왕: 5~6세기 신라 금관에서 빌린 세움 장식. 10세기 경순왕의 관으로 확인된 유물은 아니다.
- 장영실: 조선 세종대 기술자라는 배경. 후삼국 등장은 명시적 판타지이며 작업모·앞치마·도구 배치는 창작.
- 견훤·신검의 왕관과 궁예의 가사풍 군주 복식은 창작이다. 왕의 지위를 보여주는 디자인을 실제 출토품이라고 설명하지 않는다.
