## 전투 패키지 변경 금지 항목

1. 초기 적·우군·아군 슬롯, 레벨 산정, 장비, AI와 출진 필수·제외 조건.
2. 숨김·증원·퇴각·부활 명령의 발동 조건과 적용 순서.
3. 제한 턴과 그 턴을 넘겼을 때의 결과. B35/B46처럼 턴 경과가 승리인 경우를 실패로 바꾸지 않음.
4. 아이템 ID·수량·금전·획득 위치·선택 보상·일기토 보상. 한국풍 이름은 기존 아이템 교체 데이터로 표시만 변경.
5. 승리·패배의 현재 분기. 텍스트의 첫 조건만 읽어 전체 분기라고 취급하지 않음.
6. 원본 캐릭터 생존·이탈에 따른 선택 전투. 모든 전투를 체험시키려고 추가하지 않음.

원본 명령70/71의 모든 행을 합한 수를 ‘적군 수’라고 쓰지 않는다. 선택 분기, 숨김 상태, 재배치, 빈 슬롯을 구분해야 한다. 계약 JSON은 원본 명령과 참조를 보존하고 고정 수를 지어내지 않는다. 실제 테스트에서는 선택 조건을 고정한 뒤 초기 공개/초기 숨김/증원을 각각 집계한다.

## 배치 변경 단계

현재 대본 검토는 원본 위치를 사용한다. 사용자 의도에 따라 나중에 시작 위치를 바꿀 수 있으나, 아군만 멋있게 옮기지 않는다. 이동 거리·목표 도달 턴·첫 교전 턴·병목 폭·증원 접근·보물 획득 경로·퇴각 구역을 함께 비교한다. 회전·반전도 방향 의존 명령이 있을 수 있으므로 즉시 동등하다고 선언하지 않는다. 원본 배치와 변경안은 별도 저장한다.

## 도구와 검증 범위

이번에 사용한 것은 기존 추출 JSON과 Swift 코드의 읽기다. REA 신규 분석이나 바이너리 실행 검증을 수행했다고 표시하지 않는다. 모든 원본 파일에 SHA256을 남겨 향후 동일 자료를 재사용한다. 문서·데이터 참조 검사만 수행하며 원본 게임 전체 회귀검사와 사이트 빌드는 이번 문서 변경 범위에 포함하지 않는다.
