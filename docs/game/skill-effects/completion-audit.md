# 68종 스킬 연출 부족분 감사 — 2026-10-30

## 범위와 결론

이 표는 이번 보완 전 상태를 기록한다. 이미지 파일이 연결된 것, 독립 시트가 있는 것, 실제 범위와 결과를 보여주는 연출이 있는 것을 구분한다. 전체68종의 파일은 존재한다. ID0은 FireballPreview로 별도 연결되므로 skill-effects.json에 없다는 이유로 누락 처리하지 않는다.

단일·광역의 같은 효과를 공용화하는 것은 제작 계획의 의도에 맞다. 공용파일 자체는 결함이 아니다. 기존 파일을 유지하며 대상 배치와 단계·결과 연출을 보완하는 것이 우선이다. 이 감사는 기능이나 능력치를 새로 정의하지 않는다.

근거: skills.json의 id/area/range/side, skill-candidates.json의 설명, skill-effects.json 및 SkillEffectPreview.tsx의 재생 분기, skill-effects-production-plan.md. 이미지별 품질 검수 기록은 직전 full-integration 문서에 있으며 이번 감사가 이를 새로 수행했다고 뜻하지 않는다.

## 공통 부족

- 중앙 한 효과를 단독 재생해 시전자·대상과의 관계, 광역의 실제 적용 대상, 피격·회복의 흐름을 확인하기 어렵다.
- 68종 모두 실제 게임 엔진의 피해/성공/면역 판정과 연결된 것은 아니다. 이번 사이트는 명시적인 예시 장면을 제공하면 된다.
- 작은 캐릭터/대상과 효과를 함께 보여주되 전체 시트를 새로 만들지 않고 공용 좌표/순서 메타데이터를 사용한다.
- 효과 범위와 단순 장식 크기를 혼동하지 않도록 칸/대상 표식과 실제 적용 예시를 표시한다. 빈 칸에는 부대용 효과를 억지로 재생하지 않는다.
