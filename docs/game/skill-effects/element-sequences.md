# 원소·소환 남은 연출 정의

2026-10-30. 기존 경량 WebP를 보존하여 배치·진행 순서를 추가한다. 이미지 파일 자체 누락은 없으며 공용 이미지 재사용을 미완성으로 취급하지 않는다.

## 근거와 범위

- `skills.json`의 area와 `SkillRange.tsx`의 범위 해석, `skill-candidates.json`의 효과 설명, `skill-effects-production-plan.md`의 대상별 배치 원칙을 대조했다.
- ID 0–24 및64–67, 29개. 기능·MP·사거리·병과·원본 데이터는 수정하지 않았다.
- targets는 퍼센트 좌표와 프레임 지연이다. 실제 전장 좌표/범위/타격 판정이 아닌 배치 예시다. 일반 광역은 범위 안에 부대3명이 있다고 가정한다. 빈 칸마다 이펙트를 채우지 않는다.
- 일반 광역은 delay0으로 동시에 표시한다. 직선 화염은 두 프레임 간격으로 진행하고, 청룡은 네 프레임 간격의 타격 예시다.

## 통합 담당 연결 주의

- 0은 기존 FireballPreview가 투사체4+타격8로 별도 구현되어 있다. 이번 JSON의 단일 대상 정보만 참고하고 재제작하지 않는다.
- 4는 여섯 위치를 통해 직선 흐름을 구분한다. 실제 여섯 부대가 항상 존재한다는 뜻이 아니며 범위 도식으로 확인한다.
- 9/21은 시도 연출과 성공/실패 결과를 분리한다. 실패나 면역인데 자동으로 대상이 사라지면 안 된다.
- 20/22는 수집4·이동4·도착4. 이동 시트는 핵이 왼쪽, 꼬리가 오른쪽인 왼쪽 진행 방향이다. 오른쪽 대상→왼쪽 시전자 진행에 맞는다.
- 64는 소환체를 한 번 표시하고 followup 번개를 targets 순서로 표시한다. 같은 좌표 두 번 포함은 같은 적 반복 타격 가능을 보여준다. 실제 무작위 선택 및 기상 조건 판정은 구현하지 않는다.
- 66은 도입 소환 뒤 선택한 결과를 아군/적군 모두에 보여주는 예시다. 현재 결과 선택지가 전체 가능한 결과를 망라하는지는 별도 감사 항목이다.
- 67은 소환체를 한 번 표시한 뒤 각 아군에게 회복40과 정화46을 이어 보여줘야 한다. 회복만으로 상태 해제 완료를 주장하지 않는다. 능력치 변화는 유지한다.
- 기본 그림에 새 PNG를 추가하지 않아 이미지 용량 증가는0이다. 인물 및 효과는 모바일에서 겹침/잘림이 없도록 통합 UI에서 공통 크기와 여백을 확인한다.
