## 해석과 한계

기획 사이트의 연출 초안이며 실제 전투 엔진 판정을 구현한 것은 아니다. 광역/연속 타격은 대표 효과로 미리보기하고 실제 범위는 별도 범위 그림을 따른다. 청룡은 소환 뒤 단일 번개 예시이며 최대5회 무작위 타격을 구현한 화면은 아니다. 도깨비놀이/현무 결과 선택은 대표 사례다. 흡수는 수집4·이동4·도착4이며 위치는 예시다. 날씨는 전환 이펙트 초안이다.

검수 후 이번 작업 생성 원본 PNG만 정리하고 경량 WebP와 재제작 프롬프트를 유지한다. 커밋·푸시·배포는 하지 않았다.
