# 스킬 대상 병과별 피격·쇠약 연결

2026-10-30 기준 **66개 모델·승급 단계 모두 전용 지친 모션 연결**. 기존 19개를 유지하고 누락 47개에 4방향 × 4프레임, 총 752개를 추가했다. 임시 전신 기울임 반응은 제거했다.

신규 WebP 합계 3,196,120 bytes (약 3.20 MB), 프레임 평균 약 4.2 KB. 이미지 생성 원화를 잘라 축소·투명 WebP로 저장하며 부위 합성이나 CSS 회전으로 대신하지 않는다.

- 인물 카드의 쇠약 → 방향 → 재생에서 확인한다. 병과 공통 모델을 쓰는 장수는 같은 승급 단계의 프레임을 공유한다.
- 스킬의 대상 병과 선택에서도 같은 프레임을 쓴다.
- 피격 때 4프레임 재생 후 대기 복귀. HP 30% 이하 또는 상태이상 선택 시 계속 유지한다.
- 회복·강화는 피격을 유발하지 않는다. 미리보기는 실제 체력 계산·상태 해제 판정을 하지 않는다.

## 제작·검수

기존 대기 원화를 기준으로 얼굴·복식·무기·승급 특징을 유지한다. 고개와 어깨를 낮추고 숨을 내쉬는 연속 자세로 제작했다. 수레·포차는 기계가 아닌 운용자가 지친다. 동물·설화는 본래 몸 구조를 유지한다.

시트 행은 NW(11시), NE(2시), SE(5시), SW(7시) 순서. 방향 중복 9개는 원화를 재생성했고 뒤바뀐 행은 매핑으로 교정했다. 투명 간격으로 프레임을 분리하고 방향별 기존 대기 발 높이에 정렬했다. 단순 4등분 경계로 무기 끝을 자르지 않는다.

전 모델 파일 존재·빈 프레임·캔버스 가장자리 접촉·동일 프레임 중복 검사 통과. 신규 752프레임의 방향 내 발 기준선 차이는 1px 이하. 4방향 대표 프레임을 시각 검토했다. 모든 프레임의 미세한 손·복식 작화까지 최종 게임 원화로 확정한 것은 아니다.

`npm run build` 통과. 제작 기록은 `scripts/game/weakened-complete-v1-manifest.json`, 재분리 도구는 `pack-weakened-complete.mjs`, 누락/잘림 검사는 `check-weakened-complete.mjs`에 보존한다. 큰 생성 PNG는 경량본 연결과 검증 후 정리한다. 재분리는 원본을 다시 준비하고 `WEAKENED_SOURCE_DIR`로 지정해야 한다.
