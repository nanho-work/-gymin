# 미제작 인물 초상화 전체 설계안

2026-10-26 · 문서 검토 후 사용자 제작 요청에 따라 **86명 썸네일 초안을 제작·적용했다.** 아래 인물 설정은 제안이며, 제작 프롬프트와 결과는 [제작 기록](planned-portraits86-v1.md)을 참조한다.

## 범위와 원칙

- 이름 있는 인물 162개 중 초상화 연결 74개. 나머지 88개 중 사금·망실 대응 2개는 이미 설화 초상화가 있으므로 중복 생성하지 않는다. 신규 설계는 86명.
- 동일 인물 변형 미연결 7개는 기본 인물 초상화를 공유한다. 새 얼굴을 7개 더 만들지 않는다.
- 일반 부대·주민·소품 338개도 아래 부록에 전부 수록한다. 이들은 이름 있는 장수와 달리 병과·주민 역할별 공용 원화를 먼저 설계한다.
- 현재 86명은 모두 창작 가칭 슬롯이다. 아래 성별·표현 나이·계급 인상·흉터는 역사 사실이나 설정 확정이 아니다. 실제 인물로 확정된 장수의 성별·신분은 임의 변경하지 않는다.
- 원본 이름 → 교체 이름, 병과·이동거리·능력치·장비 규칙을 유지한다. 나이와 체격은 수치 변경을 뜻하지 않는다.
- 두건·관·투구는 역할을 드러내는 판타지 디자인이다. 특정 시대의 정확한 복식 복원으로 설명하지 않는다.
- 여성은 보조·치유 직군에 몰지 않는다. 강한 전열병·무도가·해적·수군·포병과 중년·노년 여성도 포함한다. 성별 자체가 강약을 결정하지 않는다.
- 얼굴형, 코·눈썹·눈매, 체격, 머리 실루엣 중 최소 3개를 가까운 인물과 다르게 한다. 같은 얼굴에 수염·색만 바꾸는 방식은 피한다.
- 상처·백발·수염이 노련함의 유일한 표현이 되지 않도록 한다. 흉터 없는 노장, 수염 없는 중년, 체격이 큰 책사도 가능하다.
- 초상화는 얼굴·어깨 중심 128×160 WebP. 인물의 대표 복식이며 플레이 기본 장비·승급 외형과는 별도다. 모자·투구가 눈과 얼굴을 가리지 않게 한다.

## 먼저 검토할 내용

1. 아래 여성 배치와 표현 나이. 모두 제안이며 원하는 인물만 바꿀 수 있다.
2. 곰부대 설해온과 맹호대 연결온은 인간 조련사 얼굴로 할지 동물 자체 초상화로 할지 결정 필요.
3. 사금·망실은 설화 목록에 초상화가 있으나 원본 대응 카드에 원본 얼굴이 남아 있는 연결 문제를 먼저 정리할 대상.
4. 가칭 확정 전에도 이미지 제작은 가능하지만, 가칭을 실제 역사 인물로 바꿀 경우 디자인을 다시 검토한다.
